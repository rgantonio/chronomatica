# DaCe Study and Tutorial

- This directory contains some exercises (with the help of AI) in order to understand how to use the DaCe tool.
- The DaCe tool is a cool tool where any program (e.g., in Python) can be analyzed and broken down into **stateful dataflow graphs**.
- A **stateful dataflow graph** is not just a dataflow graph but rather a collection of dataflow graphs linked with different states as well. It is must useful for more real-life complex systems.

# Directory Structure
- `tutorial` contains `.md` files used with explanation and exercise questions.
- `py` contains Python programs used in the corresponding tutorial exercises. It has sub-directories numbered with `pN` where `N` is the tutorial number.
